# Librerías del Proyecto Gestor Empresarial Integrado

## Dependencias requeridas

### MySQL Connector/J
- **Archivo:** `mysql-connector-j-8.0.33.jar`
- **Versión:** 8.0.33
- **Descripción:** Driver JDBC oficial de MySQL para conectar Java con la base de datos
- **Descarga:** https://dev.mysql.com/downloads/connector/j/
- **Licencia:** GPL 2.0

## Instrucciones

1. Descargar el archivo JAR desde el enlace oficial
2. Colocarlo en esta carpeta `lib/`
3. Agregar al classpath del proyecto

## Verificación

Para compilar y ejecutar, asegurarse de que el JAR esté presente:

```bash
dir lib\*.jar
